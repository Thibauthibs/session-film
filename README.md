I'm Thibaut, I help freelancers and small businesses put AI to work. After a morning where Claude Code fixed a client's website end to end (Search Console, Vercel, GitHub and Chrome, mobile Lighthouse score from 78 to 100), I wanted to show that kind of work without editing a video by hand every time. session-film is the result. You describe what happened in a small JSON story and it renders a 1080×1920 MP4 with music and sound effects, ready for Reels, Shorts or LinkedIn.

*En français : session-film transforme une session Claude Code en film 3D vertical de 30 secondes. La démo française est dans `docs/demo-fr.mp4` et le code est commenté en français.*

## What it renders

Five scenes, all built from the story with three.js:

1. **Hook.** Two to four sentences forming and morphing in glowing particles.
2. **Before.** An optional 3D phone showing the real site, a score gauge and a key number.
3. **The agent.** A glowing node wired to the tools it used. Each step sends a pulse to the right tool while a terminal types it out.
4. **Results.** A 3D gauge that bursts into particles past 90, and up to three before/after counters.
5. **Signature.** Your line and your name, with the site scrolling in the phone.

Timing, layout and soundtrack adapt to the content: number of sentences, tools, steps and numbers. Nothing is keyframed by hand.

## Quick start

```bash
git clone https://github.com/Thibauthibs/session-film
cd session-film
npm install
pip install numpy scipy   # soundtrack; without it the film is silent

node make.mjs stories/memory-cleanup/story.json --stills    # 6 key frames in stories/memory-cleanup/stills/
node make.mjs stories/memory-cleanup/story.json             # the MP4, about a minute on an Apple M-series Mac
node make.mjs stories/memory-cleanup/story.json --preview   # the same scene, live in your browser
```

You need Node 18+, Google Chrome and ffmpeg. If Chrome is not in its default location, set `CHROME_PATH`. Fonts load from Google Fonts at render time.

For a story about a website, take mobile screenshots first:

```bash
node shoot.mjs https://example.com stories/my-story
```

## Writing a story

A story is one `story.json` file. Start from `stories/memory-cleanup` (English) or `stories/memoire` (French).

| Field | What it holds |
| --- | --- |
| `name` | Short name, used for the MP4 file |
| `locale` | Number format, `fr-FR` by default |
| `hook` | 1 to 4 sentences |
| `before` | Optional. `title` lines, `screenshot`, `gauge` {value, label}, `card` {value, label, tone} |
| `agent` | `title` lines, `context` (terminal header), `tools` [{id, name}] (2 to 6), `steps` [{tool, text}] (2 to 8), `validated` |
| `results` | Optional. `title`, `subtitle`, `gauge` {from, to, label}, `cards` [{label, before, from, to, decimals, unit}] (1 to 3), `footnote` |
| `end` | `title` lines, `name`, `scroll` (full-page screenshot that scrolls in the phone) |
| `phone` | `time` shown in the status bar |

Wrap accent words in `*stars*` and split a hook sentence over two lines with `|`. Long titles shrink to fit on their own.

## From Claude Code

Copy `skill/SKILL.md` to `~/.claude/skills/session-film/SKILL.md`. At the end of a session, ask Claude to "make a film of this session". It gathers what was actually done, writes the story, checks the key frames and renders the film.

## Ground rules

The film only shows numbers measured during the session, never estimates. Client data that is not public (traffic, calls, revenue) stays out unless the client agrees. The whole point is to show real work.

## How it works

`engine/timeline.js` turns a story into a timeline and is shared by the browser and Node. `engine/film.js` builds the three.js scene plus an HTML layer for the typography. Everything is a pure function of time, so `make.mjs` can drive headless Chrome frame by frame through `window.renderAt(t)`, pipe the screenshots into ffmpeg and mux the soundtrack generated by `engine/audio` (music and sound effects synthesized with numpy, no samples). Chrome renders on the GPU, which is why a full film takes under a minute.
